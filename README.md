# Wright Cut Barbershop - Work Integrated Learning (WIL 3A)

##  Project Overview
Wright Cut Barbershop is a full-featured grooming management system designed for a local barbershop established in Ga-Rankuwa. The system includes a responsive web application and an Android mobile application backed by a cloud database.

## Project Team & Stakeholders
- **Stakeholder / Client:** Wright Cut Barbershop (Founded by Boikhutso Maswanganyi & Kagiso Maluleka)
- **Location:** 932 Monato Street, Ga-Rankuwa View, Zone 15, Gauteng
- **Institution:** Faculty of Information and Communications Technology

##  Key Features
- **User Authentication:** Email/Password authentication and Single Sign-On (Google SSO).
- **Security Verification:** Two-channel OTP verification (Email verification via EmailJS & SMS dispatch).
- **Cloud Database (Firebase Firestore):** Real-time cloud storage for registered users, appointments, and service menus.
- **Role-Based Access Control (RBAC):** Designated Administrator portals with client appointment scheduling.
- **Interactive Hairstyle Gallery:** Image modal lightbox with navigation and mobile-first responsive layout.
- **Live GPS Navigation:** Embedded Google Maps integration for salon location and directions.
- **Smart Booking System:** Real-time checking against booked slots to prevent double-booking.

##  Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6 Modules)
- **Backend & Database:** Google Firebase (Authentication & Cloud Firestore)
- **Email Service:** EmailJS Cloud API
- **Mobile Platform:** Capacitor / Android Studio
- **Version Control & DevOps:** Git, GitHub
